# Personal Portfolio Website

## About the Project
This is my personal portfolio website created as part of my college assignment. It introduces me, showcases my interests and academic achievements, and demonstrates my knowledge of HTML and CSS.

## Technologies Used
- HTML5
- CSS3

## Features
- Personal introduction and About Me section
- Profile photo
- Hobbies and interests
- Academic achievements section
- Custom background image
- Styled headings, text, and sections
- CSS examples demonstrating selectors and styling properties
- Contact section

## CSS Concepts Used
- Element, class, and ID selectors
- Colors using HEX, RGB, and RGBA values
- Background images and background properties
- Font styles, font sizes, and text alignment
- Width, height, margin, and padding
- Borders and border radius
- CSS Box Model
- Visibility and other styling properties

## Project Structure
- `index.html` — Structure and content of the website
- `style.css` — Styling and visual design
- `background.png` — Website background image
- Other image files — Images used in the portfolio

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your web browser.

## Learning Outcomes
This project helped me understand how HTML creates the structure of a webpage and how CSS improves its appearance using selectors, colors, backgrounds, typography, spacing, borders, and the box model.
